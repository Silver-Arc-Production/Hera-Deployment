How to read this

Every listing moves each tick from drift, a market regime scaled by the stock's beta, mean reversion toward fair value, news events and noise. Circuit breakers halt a name after a sharp collapse. The dashboard is a window onto that simulation — it reads the same database the Discord commands do and never writes to it.
